# QAZ PVH, демо-сайт натяжных потолков

Одностраничный сайт для QAZ PVH, центра натяжных потолков в Астане (Instagram @qaz_pvh, 2ГИС).

- `index.html`: вся страница (HTML, CSS и JS в одном файле, без сборки).
- `img/`: два фото работ из 2ГИС и первая страница экспертного заключения на плёнку FOLIEN ECO PREMIUM.

Номер WhatsApp и текст сообщения меняются в одном месте, в конце `index.html` (`WA_PHONE`, `WA_TEXT`).

Данные взяты из Instagram компании и карточки 2ГИС (ноябрь 2026). Цен на сайте нет: в 2ГИС их не указано, поэтому вместо прайса форма расчёта, которая открывает WhatsApp.
